### BUILD 14: 리버스 드라이브와 실제 픽셀 VFX

첫 보스 구간의 Q를 제자리 삼연타에서 **추진 → 무릎 타격 → 피스톤 킥 → 착지**로 교체했습니다. 전용 전신 스프라이트 8프레임을 생성하여 실제 타격 시점에 재생합니다. 총 기본 피해는 39로 유지하고, 전진 중 보스를 통과하거나 벽을 벗어나지 않도록 제한했습니다.

패링 또는 적 공격을 통과하는 대시 회피에 성공하면 **리버스 드라이브 1회**를 회수합니다. 6초 안에 Q를 쓰면 추진 거리가 늘고 SP 비용이 24에서 12로 줄며 Q 재사용 대기시간을 한 번 무시합니다. 피해량이나 무적은 추가되지 않습니다. 패링 직후 K를 유지한 상태에서도 Q로 전환할 수 있습니다. 이후 보스에는 적용하지 않습니다.

별도로 생성한 투명 PNG VFX 시트의 **발뒤꿈치 분사 4프레임 / 금속 충돌·파편 4프레임**을 Q·회피·명중·피격·패링에 적용하고 레일 발사구와 E 말뚝 작동에도 재사용했습니다. 문자나 새 도형 오버레이로 대신하지 않았습니다. 프레임별 중심점과 잘린 망토 조각을 실제 렌더러에서 보정했습니다.

SURGEON은 후퇴 후 0.7초간 방향을 예고하고 견제탄으로 응수합니다. E로 봉합 이동을 고정하면 이 후퇴 견제도 취소할 수 있습니다. 첫 보스 이후 규칙은 유지합니다.

### BUILD 13: 기계 다리와 봉합 장치의 공방

변경 범위는 첫 작전과 SURGEON까지입니다. 이후 보스의 기존 플레이어 규칙은 유지합니다.

- ZERO의 대기·공중·J/Q 마지막 타격을 같은 다리 전투 시트로 연결하고, 자세가 바뀌는 시점을 실제 타격 시점에 맞췄습니다. 달리기는 이동량으로 프레임을 진행하며 공중 달리기와 공격 도중 반전 현상을 막았습니다. 이번 작업은 기존 스프라이트 재사용과 상태·타이밍 개선이며, 새 중간 프레임 제작은 아닙니다.
- J는 견제 → 전진 상승각 → 내려찍기, K는 다리 고정·패링·충전, W는 경골 레일건, E는 전방 접지 말뚝, R은 압착 단두각으로 역할을 구분합니다.
- SURGEON은 중립 상태에서 연속 피해를 받으면 0.38초간 후퇴를 예고하고 거리를 벌립니다. 무적이나 자동 반격 피해는 없으며, 후퇴 남발을 막는 간격이 있습니다. 공격 후 기존 반격 시간은 보존하고 다음 준비까지의 대기를 줄였습니다.
- J/K 적중 후 Q 연타 또는 E 이동 고정을 선택할 수 있습니다. E는 전방 고정 위치에 발동하며 SURGEON에 맞으면 이동을 1.4초간 막습니다. 예고된 후퇴를 끊을 수 있지만 보스 공격 자체를 봉쇄하지는 않습니다. SP와 재사용 대기시간은 유지합니다.
- 첫 구간 Q의 긴 무적을 제거하고 피격 시 미발동 연계 타격을 취소합니다. 공격 중에도 방향키+Shift로 뒤로 빠질 수 있습니다.

[변경된 J 동작](docs/previews/neural-j-frames.png) · [J→E로 보스 후퇴를 막는 실제 화면](docs/previews/anchor-duel.png)

컨셉의 중심은 **자신의 몸을 무기로 개조한 ZERO**와 **전장을 수술대로 만드는 SURGEON**의 주도권 다툼입니다. 사이버펑크·미래 기술은 기계 다리의 서로 다른 작동 방식으로, 다크판타지·신화는 수술 성당과 봉합 프로토콜/역류로 표현합니다. 다음 비주얼 우선순위는 무게 이동을 연결하는 전용 중간 프레임과 보스 장치의 후퇴·고정 반응입니다. 새 전투 체계나 이후 보스 확장은 포함하지 않습니다.

검증: 자동 테스트 91개, 실제 브라우저 J→E 후퇴 차단, 공격 프레임, 연타·양쪽 벽·공중·피격·대시·재시작, 궁극기 회피와 패링→반격.

### BUILD 12: SURGEON 신경 봉합 프로토콜

첫 보스가 체력 절반 이하에서 한 번 사용하는 궁극기를 추가했습니다. 위치가 고정되는 봉합 낙하 두 차례 → 최종 낮은 절개 순서입니다. 낙하는 표식 밖으로 이동하고, 절개는 점프·회피·정면 K 패링으로 대응합니다. 마지막 절개를 패링하면 봉합 역류로 2.1초의 반격 시간이 생깁니다. 자동 추가 피해나 SP 보상은 없습니다. 최대 차징으로 준비 동작을 끊으면 해당 궁극기는 취소되며 다시 사용하지 않습니다.

단계 표시와 준비·발동음을 추가하고 기존 보스 스프라이트를 재사용했습니다. 보스가 공격 중일 때 뒤로 넘어가도 자세와 타격 방향이 일치합니다. 이후 보스·스테이지·보상은 변경하지 않았습니다.

검증: 자동 테스트 83개, 30/60fps에서 양쪽 벽·중앙 무패링 회피, 브라우저에서 두 낙하와 최종 절개 회피 및 K 패링→J 반격. `tests/protocol_smoke.py`는 첫 보스의 이 경로만 검사합니다.

### BUILD 11: 첫 보스 패링 시험

SURGEON의 낮은 절개가 닿기 직전, 지상에서 보스를 향해 K를 누르면 0.12초간 패링합니다. 성공 직후 J로 반격하거나 K 차징을 계속할 수 있습니다. J는 원래 사거리 안에서만 맞습니다. 패링은 추가 피해·SP·무적을 주지 않으며 재입력으로 방어 시간을 연장하지 못합니다. 점프와 회피도 그대로 유효합니다. 공격 중 예약한 K·공중·등 뒤 공격·다른 보스에는 패링이 적용되지 않습니다. 기존 무릎을 든 프레임과 짧은 금속음·국소 충돌 효과를 재사용합니다.

**바로 실행:** Node.js 24 LTS 설치 → 프로젝트 폴더에서 `npm install` → `npm run dev`. 브라우저가 자동으로 열립니다. [설치·실행·문제 해결 안내](#로컬에서-바로-플레이하기)

화면 오른쪽 위 **BUILD 14 · REVERSE DRIVE**로 버전을 확인하세요.

ZERO는 기계 다리를 펼쳐 차고 찍는 근접 전투원, SURGEON은 수술 장치로 거리를 통제하는 보스입니다. J의 덧붙인 도형 다리를 제거하고 새 전신 공격 시트와 보스의 낮은 절개 자세를 생성·적용했습니다. 준비 → 타격 → 회수 자세를 재생하며, 일부 동작은 기존 프레임을 재사용합니다.

SURGEON은 거리에 따라 접근·후퇴하고 절개·낙하·바늘 견제를 선택합니다. 공격 방향은 예고 때 고정되고, 공격 후 반격할 시간이 생깁니다. K로 시전을 끊은 직후에는 4초간 연속 시전 중단이 제한됩니다. 실제 온라인 PvP는 아닙니다.

J/K 적중 → Q → Q 마지막 타격 적중 → R 연결은 유지합니다. Q의 세 타격을 자세 변화에 맞췄고, J와 R의 판정을 실제 다리 범위에 맞게 줄였습니다. E는 지상에서 전방 한 곳에 말뚝을 박으며 SP 24 / 재사용 3초입니다. K 최대 충전은 0.65초입니다.

## 이전 타격 피드백 개선

이번 버전은 기존 전투의 타격 피드백을 다듬었습니다. 명중 순간에만 강도별 충격음·짧은 섬광·방향성 반동이 나오고, HUD는 흔들리지 않습니다. 타격 정지는 22/42/65ms로 구분하고 카메라 반응은 최대 1.8 게임 픽셀로 제한했습니다. 피해량·사거리·공격 시간·적 패턴·SP 비용은 유지했습니다.

타격 정지 중 점프 입력, 피격 시 공중 상태와 자세, 재시작 시 잔여 효과를 수정했습니다. 궁극기 배너는 짧게 표시하고 입자량을 줄였습니다. [진단·우선순위·두 차례 조정 내역](docs/COMBAT_AUDIT.md)을 확인할 수 있습니다.

![BUILD 08 명중 반응](docs/previews/impact.png)

이번 점검에서는 공격 동작 끝나기 직전의 입력을 0.22초간 한 번 예약하도록 개선했습니다. 타격 정지 중 입력도 보존하며, 피격·회피·일시정지 시 공격 예약은 취소됩니다. J는 짧은 절단 → 올려 베기 → 긴 마무리로 연결되고, 상단에 3연타 단계가 표시됩니다. 키를 계속 누르는 것만으로 자동 연타되지는 않습니다. 기술은 앞선 동작이 끝난 뒤 연결되며 동시에 동작을 덮어쓰지 않습니다.

Q 삼연 절단이 짧은 피격 무적 때문에 두 번만 맞던 문제도 수정했습니다. 30fps·60fps에서 모두 세 타격을 확인했습니다. 명중 위치에는 강도에 따른 짧은 섬광을 추가했습니다.

## 이번 전투 변경

- **K 유지 → 해제**: 짧게 누르기 / 0.4초 충전 / 0.65초 최대 충전으로 피해와 사거리가 달라집니다. 최대 충전의 `BREAK READY`를 보고 놓으세요. 화면의 K 버튼도 길게 눌렀다 놓습니다.
- **회피 우선**: 충전 중 이동 가능. Shift·피격·일시정지·창 전환은 충전을 취소합니다. 주인공 표시 크기와 몸통 피격 영역을 줄였고 이동 속도와 회피 거리를 늘렸습니다. 망토와 무기 끝에는 피해를 받지 않습니다.
- **SURGEON 공방**: 위치가 고정되는 세 줄 낙하, 방향이 고정되는 주사기 산개, 점프로 넘을 수 있는 낮은 절개. 붉은 예고를 보고 피한 뒤 `EXPOSED` 때 반격하면 피해가 25% 증가합니다. 최대 차징을 시전 중 적중시키면 시전을 끊고 긴 빈틈을 만듭니다. 미리 충전하고 접근하는 전략도 가능합니다.
- **구분되는 기술 효과**: Q 삼연 칼날, W 청록색 레일 궤적, E 금속 말뚝, R 압착 단두각. 주사기는 약통과 바늘을 표시합니다. 충전 단계 음향과 강타의 타격 정지 효과도 추가했습니다.
- **잡몹 회피**: 드론의 사격 방향을 점선으로 예고하고 예고 후에는 플레이어를 다시 추적하지 않습니다.

## 로컬에서 바로 플레이하기

**필수:** Node.js 22.12 이상(권장: Node.js 24 LTS, npm 포함), 최신 Chrome/Edge/Firefox와 키보드. [Node.js 설치](https://nodejs.org/) 후 터미널을 새로 여세요.
게임 자체에는 백엔드·데이터베이스·API 키가 필요 없습니다. 로컬 서버용 개발 의존성은 Vite 8.3.5이며 버전은 `package-lock.json`에 고정했습니다.

1. GitHub의 **Code → Download ZIP**으로 다운로드하고 압축을 풀거나 `git clone https://github.com/jjh0124124/EDEN.git`을 실행합니다.
2. **package.json이 들어 있는 폴더**에서 터미널을 엽니다. ZIP 폴더 이름은 보통 `EDEN-main`, clone한 폴더는 `EDEN`입니다.
3. 처음 한 번 설치합니다.

```bash
npm install
```

4. 실행합니다. 다음부터는 이 명령 하나만 실행하면 됩니다.

```bash
npm run dev
```

기본 브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 `http://127.0.0.1:4173`을 입력하세요. 서버를 실행한 터미널은 그대로 두고, 종료하려면 **Ctrl+C**를 누르세요.

**플레이 시작:** 화면 아래 **시작 / 이어하기** → **구역 진입** → **대사 다음**으로 통신을 넘긴 뒤 A/D 이동, Space 점프, J 공격, K 길게 누르고 놓기로 충전 공격을 합니다. 첫 보스까지의 경로는 아래 ‘첫 작전’을 참고하세요.

진행 상황은 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저와 주소를 사용해야 이어집니다. `localhost`와 `127.0.0.1`은 저장 공간이 다릅니다.

### 실행 문제 해결

- `node`/`npm`을 찾지 못하면 Node.js 설치 후 터미널을 다시 열고 `node --version`을 확인하세요.
- PowerShell에서 `npm.ps1` 실행이 차단되면 `npm.cmd install`, `npm.cmd run dev`를 사용하세요. 실행 정책을 바꿀 필요는 없습니다.
- 4173 포트가 사용 중이면 기존 EDEN 서버를 Ctrl+C로 종료하거나 `npm run dev -- --port 4174`를 실행하세요. 주소도 `http://127.0.0.1:4174`로 바뀝니다.
- 창을 전환한 뒤 멈췄다면 **계속하기** 또는 Esc를 누르세요. 통신 중에는 먼저 대사를 넘겨야 이동할 수 있습니다.
- `index.html` 더블클릭 대신 위 HTTP 서버 실행을 권장합니다. Python 3가 이미 있다면 의존성 설치 없이 `python3 -m http.server 4173 --bind 127.0.0.1`도 가능합니다(Windows는 `py` 사용).

### 개발 검증(플레이할 때는 불필요)

```bash
npm test
```

브라우저 진입 테스트는 별도 선택 의존성인 Python 3, Playwright, Chromium을 사용합니다. `npm run dev`가 실행 중인 상태에서 다른 터미널로 실행하세요.

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/local_start_smoke.py
```

Windows에서는 `python3` 대신 `py`를 사용하세요. 테스트는 독립적인 브라우저 저장 공간에서 시작 버튼·대사·이동·점프·J·K·일시정지·재개와 에셋 로딩을 확인합니다. 기존 Chromium을 쓰려면 `CHROMIUM_PATH` 환경 변수로 실행 파일을 지정할 수 있습니다. 재현 가능한 의존성 재설치는 `npm ci`를 사용하세요.

## 조작

- `A` / `D`: 이동
- `←` / `→`: 이동 (한글 입력 상태에서도 물리 키로 처리)
- `Space`: 점프
- `Shift`: 회피
- `J`: 기본 공격 / `K`: 누르고 충전, 놓으면 공격
- `Q` / `W` / `E` / `R`: 전투 기술
- `Esc`: 일시정지
- `F`: 단말 조사 / 보스 구역 접속
- `M`: 음소거
- 메뉴: 방향키 또는 `W` / `S`, `Enter`

화면 아래의 **시작 / 대사 다음** 버튼으로 진행할 수 있습니다. **← 이동 / 이동 →** 버튼을 마우스나 터치로 길게 누르면 이동합니다. 통신 화면에서는 대사를 넘긴 뒤 이동할 수 있고, 다른 창으로 전환해 일시정지됐다면 **계속하기**를 누르세요.

## 첫 작전

통신을 Enter로 읽은 뒤 D로 전진하세요. 첫 회랑의 단말은 F로 조사할 수 있습니다. 다음 격실에서 드론 두 대를 제거하면 문이 열립니다. 마지막 격실 오른쪽 문 앞에서 F를 누르면 보스전에 진입합니다. 재정비 때 체력이 회복되며 보스 앞 체크포인트가 저장됩니다.

Q: LAHAT 삼연 절단 / W: RAIL 관통탄 / E: PILE 전방 말뚝 / R: KETER 압착 단두각.
일반 공격 적중으로 SP를 회복합니다. 코어 회수당 공격력이 8%, 최대 체력이 5 증가합니다.
WARDEN의 정면 장갑에는 K 강 공격으로 과부하를 누적하세요.

## 현재 범위

7보스 기본 전투·2페이즈, 고유 장비와 공격, 기록 조사·보안 드론·재정비 구간, 대사, 코어 강화, 체크포인트, 재도전, 엔딩 기록을 구현했습니다. 관절형 캐릭터와 구역별 배경, 회피 잔상, 타격 정지, 위험 지대, 합성 금속음과 산업적 음악을 사용합니다.

**목표인 4시간 분량은 아직 아닙니다.** 새 이미지 에셋의 주 적용 범위는 ZERO, SURGEON, 수술 성당입니다. 나머지 여섯 보스는 관절형 절차 렌더링을 사용하며 순차 교체가 필요합니다. ZERO의 점프·피격 및 일부 기술은 기존 프레임을 공유하므로 모든 동작에 전용 프레임이 완성된 상태는 아닙니다. 고유 레벨, 추가 모션, 음악 마스터링, 장시간 난이도 검증이 남았습니다. 화면 조작 버튼은 마우스·터치를 지원하지만 실제 모바일 기기별 검증은 아직 필요합니다.

저장은 같은 브라우저와 주소에 종속됩니다. 브라우저 데이터를 지우면 기록도 사라집니다.

## 검증

```bash
node --check src/game.js
node --check src/presentation.js
node --test tests/combat.test.cjs
```

선택적 브라우저 검증: Playwright Python과 Chromium 설치 환경에서 로컬 서버 실행 후 `python3 tests/browser_smoke.py`. `CHROMIUM_PATH`로 실행 파일 위치를 지정합니다. 테스트 제어 인터페이스는 테스트가 가로챈 응답에만 들어가며 게임에는 포함되지 않습니다.

`src/game.js`: 전투·진행·저장·입력. `src/presentation.js`: 그림·관절·배경 캐시·음향. 다음 작업은 `docs/DEV_LOG.md`를 참고하세요.
