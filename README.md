## 로컬에서 바로 플레이하기

**필수:** Node.js 22.12 이상(권장: Node.js 24 LTS, npm 포함), 최신 Chrome/Edge/Firefox와 키보드. [Node.js 설치](https://nodejs.org/) 후 터미널을 새로 여세요.
게임 자체에는 백엔드·데이터베이스·API 키가 필요 없습니다. 로컬 서버용 개발 의존성은 Vite 8.3.5이며 버전은 `package-lock.json`에 고정했습니다.

1. GitHub의 **Code → Download ZIP**으로 다운로드하고 압축을 풀거나 `git clone https://github.com/jjh0124124/EDEN.git`을 실행합니다.
2. **package.json이 들어 있는 폴더**에서 터미널을 엽니다. ZIP 폴더 이름은 보통 `EDEN-main`, clone한 폴더는 `EDEN`입니다.
3. 처음 한 번 설치합니다.

```bash
npm install
```

4. 실행합니다. 다음부터는 이 명령 하나만 실행하면 됩니다.

```bash
npm run dev
```

기본 브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 `http://127.0.0.1:4173`을 입력하세요. 서버를 실행한 터미널은 그대로 두고, 종료하려면 **Ctrl+C**를 누르세요.

**플레이 시작:** 화면 아래 **시작 / 이어하기** → **구역 진입** → **대사 다음**으로 통신을 넘긴 뒤 A/D 이동, Space 점프, J 공격, K로 패링을 합니다. 첫 보스까지의 경로는 아래 ‘첫 작전’을 참고하세요.

진행 상황은 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저와 주소를 사용해야 이어집니다. `localhost`와 `127.0.0.1`은 저장 공간이 다릅니다.

### 실행 문제 해결

- `node`/`npm`을 찾지 못하면 Node.js 설치 후 터미널을 다시 열고 `node --version`을 확인하세요.
- PowerShell에서 `npm.ps1` 실행이 차단되면 `npm.cmd install`, `npm.cmd run dev`를 사용하세요. 실행 정책을 바꿀 필요는 없습니다.
- 4173 포트가 사용 중이면 기존 EDEN 서버를 Ctrl+C로 종료하거나 `npm run dev -- --port 4174`를 실행하세요. 주소도 `http://127.0.0.1:4174`로 바뀝니다.
- 창을 전환한 뒤 멈췄다면 **계속하기** 또는 Esc를 누르세요. 통신 중에는 먼저 대사를 넘겨야 이동할 수 있습니다.
- `index.html` 더블클릭 대신 위 HTTP 서버 실행을 권장합니다. Python 3가 이미 있다면 의존성 설치 없이 `python3 -m http.server 4173 --bind 127.0.0.1`도 가능합니다(Windows는 `py` 사용).

### 개발 검증(플레이할 때는 불필요)

```bash
npm test
```

브라우저 진입 테스트는 별도 선택 의존성인 Python 3, Playwright, Chromium을 사용합니다. `npm run dev`가 실행 중인 상태에서 다른 터미널로 실행하세요.

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
```

Windows에서는 `python3` 대신 `py`를 사용하세요. 테스트는 독립적인 브라우저 저장 공간에서 시작 버튼·대사·이동·점프·J·K·일시정지·재개와 에셋 로딩을 확인합니다. 기존 Chromium을 쓰려면 `CHROMIUM_PATH` 환경 변수로 실행 파일을 지정할 수 있습니다. 재현 가능한 의존성 재설치는 `npm ci`를 사용하세요.

## 조작

- `A` / `D`: 이동
- `←` / `→`: 이동 (한글 입력 상태에서도 물리 키로 처리)
- `Space`: 점프
- `Shift`: 입력 방향으로 회피 이동. 자동 공격은 없습니다.
- `J`: 좌우 손이 교대하는 염동 잽. 적중 후 Q/W/E/R로 연결하며, 빗나가거나 방어당하면 연결되지 않습니다.
- `K`: 짧은 패링. 성공 시 궁극기 게이지를 얻습니다.
- `Q`: 역장 분출. 회복 중인 SURGEON의 자세를 무너뜨리며 보스는 바닥에 남습니다. E로 압축한 보스를 밀어내 거리를 벌릴 수도 있습니다.
- `W`: 전방 역장 파열. E로 압축한 적을 맞히면 압축을 소모해 추가 폭발이 발생합니다.
- `E`: 중거리 염동 속박. 적중하면 2.4초 압축 상태를 만들고 Q로 밀어내거나 W로 터뜨릴 수 있습니다. 보스의 방어를 깨지만 공격 중인 보스와 재포획 제한 중인 보스에게는 실패합니다.
- `R`: ZERO POINT. 게이지 100에서 사용하며, 첫 타격이 명중해야 전용 컷인과 1.55초의 속박·압축·대폭발 연출로 연결됩니다. 방어되거나 빗나가면 게이지를 잃습니다.

Q/W/E는 SP 외에 각각 1.25초, 2.1초, 2.8초의 재사용 시간이 있습니다. 화면 아래 아이콘에 남은 시간이 표시됩니다.

새 전투와 생성한 격투 스프라이트는 첫 작전부터 SURGEON까지만 적용됩니다. SURGEON 이후 구간은 없습니다.

- `Esc`: 일시정지
- `F`: 단말 조사 / 보스 구역 접속
- `M`: 음소거
- 메뉴: 방향키 또는 `W` / `S`, `Enter`

화면 아래의 **시작 / 대사 다음** 버튼으로 진행할 수 있습니다. **← 이동 / 이동 →** 버튼을 마우스나 터치로 길게 누르면 이동합니다. 통신 화면에서는 대사를 넘긴 뒤 이동할 수 있고, 다른 창으로 전환해 일시정지됐다면 **계속하기**를 누르세요.

## 첫 작전

통신을 Enter로 읽은 뒤 D로 전진하세요. 첫 회랑의 단말은 F로 조사할 수 있습니다. 다음 격실에서 드론 두 대를 제거하면 문이 열립니다. 마지막 격실 오른쪽 문 앞에서 F를 누르면 보스전에 진입합니다. 재정비 때 체력이 회복되며 보스 앞 체크포인트가 저장됩니다.

SURGEON을 처치하면 승리 화면으로 끝납니다. 이후 보스·스테이지·보상 선택은 삭제했습니다. 예전 저장이 이후 구간을 가리키면 첫 회랑으로 복구합니다.

SURGEON은 가까운 거리에서 방어가 끝나면 절개로 반격합니다. E로 방어를 깨거나 미리 거리를 벌리고, 반격이 예고되면 점프 또는 K 패링으로 대응하세요.

SURGEON의 체력은 1,800입니다. 관통 주사는 점프 또는 정면 K 패링으로 피하고, 교차 봉합은 양옆 낙하가 지난 뒤 중앙 표식에서 이동하세요. 수술 장치 두 개를 모두 파괴하면 필살기를 저지할 수 있습니다. 하나만 파괴했다면 그 지점이 안전지대가 되고, 파괴하지 못해도 지면 파동을 점프로 피할 수 있습니다. 2페이즈 후반에는 더 짧은 시간으로 수술 장치가 다시 전개됩니다. 장치가 작동 중일 때 보스 본체는 보호되며 R 게이지는 소모되지 않습니다. 일부 절개는 플레이어 위치를 노리는 낙하 공격으로 이어지며, 절개를 K로 패링하면 후속 공격이 취소됩니다.

첫 회랑의 기록 조사와 보안 드론, 재정비, SURGEON의 두 페이즈, 사망·재시도·승리까지 플레이할 수 있습니다. 일반 공격은 SP를 회복하며 스킬은 SP를 사용합니다.
