# EDEN — 개발 기록

## 방향

사용자가 지정한 우선순위: **사이버펑크 → 미래 기술 → 기계 → 다크 판타지 → 신화**.
ZERO(특수전투개체 00)의 기계 다리와 남성 실루엣을 유지한다. 검정·차콜·은색·백색에 강한 적색을 사용한다. 신화는 기술과 통제 시스템의 명칭·연출로 표현한다.

보스 순서: SURGEON → HOUND → WARDEN → SERAPH → ORACLE → EXODUS → DIRECTOR.
최종 목표: 의미 있는 탐색·전투·서사로 약 4시간. HP·대기·반복으로 길이를 부풀리지 않는다.

## 출발점과 실제 상태

처음 제공된 문서는 기존 3보스와 약 60분 분량을 전제로 했으나 실제 체크아웃은 비어 있었다. 기존 게임 코드는 제공되지 않았다. 현재 코드는 새로 구축한 개발 버전이며 과거 게임을 확장한 결과라고 간주하면 안 된다.

수정한 오류: 강 공격과 HOUND 공격이 준비 도중 사라지던 문제, ORACLE의 비동기 타이머와 이동 표적, 위로만 향하던 탄막, EXODUS의 반대 방향 투사체, 제자리 회피 감속, 사망 후 입력, 처치 후 위험물, 엔딩 기록 삭제.

현재 구현: 7보스 기본전·2페이즈·장갑 과부하, 보스 사이 기록·드론·재정비 구간, 코어 강화, 대사, 관절형 렌더링, 7배경 변형, 피격 효과, 합성 음악과 효과음, 자동 저장 및 엔딩 기록.

## 에셋 정책

BUILD 04에서 내장 이미지 생성 도구로 ZERO 전투용 프레임, SURGEON 자세, 수술 성당 배경을 제작했다. 프레임별 기준점을 지정하고 최근접 샘플링으로 게임에 연결했다. 이전 고해상도 비픽셀 원화는 게임에 넣지 않았다. PixelLab·Higgsfield는 호출 가능한 도구가 없어 사용하지 않았다. 콘셉트 시트를 잘라 캐릭터로 쓰지 않는다. 출처와 통합 방식은 `assets/THIRD_PARTY_ASSETS.md`에 기록한다.

이동 입력은 물리 키 코드로 수정했으며 한글 입력, 마우스·터치 버튼, 포커스 이탈 후 재개를 검증한다. ZERO의 손 무기를 제거하고 기계 다리의 변형 공격으로 변경했다. 화면 상단 빌드 번호로 이전 다운로드와 구분할 수 있다.

## 남은 우선 작업

1. 일반 플레이어의 첫 보스 클리어까지 직접 플레이하며 난이도·명중 범위를 조정.
2. 반복되는 3구간 구조를 고유 공간과 환경 상호작용으로 확장.
3. ZERO와 SURGEON의 프레임·관절 애니메이션과 전용 피격·사망 동작 강화.
4. 보스별 패턴, 공간 기믹, 스토리 장면과 고유 음향을 점진적으로 완성.
5. 실제 플레이타임 측정과 전체 캠페인 균형 검증. 현재 4시간 목표는 미달.

작동하는 코드를 보존하고 변경 범위에 맞는 테스트를 실행한다. 구현 여부와 플레이 검증 여부를 구분한다.

## BUILD 04 검증

Node 회귀 테스트 19개 통과. Chromium에서 한글 물리 키, 마우스 홀드, 터치 종료·취소, 일시정지 복구를 확인했다. 이미지 에셋 3종의 로드와 ZERO의 서로 다른 16자세를 실제 렌더러에서 확인했다. 7보스 강 공격·페이즈 전환·엔딩 저장 검사도 통과했다. 이 검사는 정상 난이도의 전체 게임 클리어 또는 4시간 플레이 테스트를 뜻하지 않는다.

관리형 브라우저의 file:// 제한으로 파일 더블클릭 실행 검증은 건너뛰었으며 HTTP 실행은 검증했다. Higgsfield 연동은 제공되지 않아 내장 이미지 생성 도구를 사용했다.

## BUILD 05 — CORE REFORGE

- 1~6보스 처치 뒤 영구 개조 선택: RAZOR 공격력 가산 12%, FLUX SP 재생 +3/초 및 재사용 회복 속도 +15%, AEGIS 최대 체력 +20 및 피해 감소 8%(최대 40%). 기존 코어 자동 강화에 추가로 적용하며 같은 계열을 반복 선택할 수 있다.
- 미선택 보상을 별도 체크포인트로 저장. 새로고침 후 다시 보스를 잡을 필요 없이 선택부터 재개한다. 이전 버전 저장에는 개조 레벨 0을 적용한다.
- 키보드 A/D, 방향키와 화면 이동 버튼으로 선택 가능. 카드 직접 터치와 기존 진행 버튼으로도 이식 가능.
- 연속 타격 계기(2.4초, 피격 시 끊김), 처치 레터박스와 해체 프레임, 최고 연속 타격·전투 시간 표시.
- 구역별 팔레트와 비·재·발광 입자. 추가 이미지 생성 API 호출 없음. 전투 밸런스와 전체 플레이타임은 별도 장시간 검증 필요.
- Chromium에서 보상 저장 복원, 실제 터치 입력, 개조 후 체력 적용과 기존 7보스 페이즈·엔딩 검증. 기존 픽셀 캐릭터 스프라이트는 유지했으며 이번 변경은 새 캐릭터 원화 제작이 아니다.

## BUILD 06 — SURGEON REWORK

- K 홀드/해제 차징: 0 / 0.4 / 0.95초 단계, 피해 22 / 34 / 52, 사거리 62 / 82 / 104. 최대 충전으로 SURGEON 시전을 끊으면 2초 취약 상태. 일반 공격 후에도 1.45초 취약 상태가 있고 이때 피해 25% 증가.
- ZERO 높이 60→48, 생성 스프라이트 배율 .24→.20. 실제 피격은 안쪽 11×36 영역. 일반 이동 92→112, 회피는 300 속도·.28초·.34초 무적. 회피 중 방향이 뒤집히지 않음.
- 충전 중 이동 70. 회피·피격·일시정지·블러·터치 취소 시 충전 취소. 터치 종료와 마우스 버튼 밖에서의 해제는 정상 발동.
- SURGEON의 3패턴: 고정 표식 낙하 / 고정 방향 주사기 / 낮은 수평 절개. 기본 예고 1초, 2페이즈 .8초. 공격 후 재공격 대기 2.4 / 2초. 중립 상태에서 가까운 플레이어와 거리를 벌린다.
- 드론 사격 예고 .75초, 속도 85, 사격 간격 3.1초. 점선으로 발사 방향을 표시.
- 기존 원호 슬래시를 기술별 픽셀 선분·격자·칼날로 교체. 레일 궤적·금속 말뚝·약통 바늘과 HUD 기술 아이콘을 분리. 새 이미지 API 호출 없이 런타임 애니메이션으로 제작. 캐릭터 본체의 모든 동작을 새 스프라이트로 제작한 것은 아님.
- 검증: Node 전투 테스트 37개. 실제 Chromium에서 K 키보드/마우스/터치 홀드·해제와 터치 취소, 기존 이동·블러 복구, 7보스 공격·페이즈·엔딩 저장 확인. 첫 보스의 표식 회피·피격 대조, 점프 회피, 최대 충전 시전 차단을 자동 검증. 장시간 사람 플레이에 의한 최종 난이도 조정은 아직 필요.
