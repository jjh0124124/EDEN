# Third-party assets

EDEN currently uses no external visual, audio, font, or code assets.

All current graphics, animation layers, particles, and sound effects are generated at runtime by project code. `src/presentation.js` contains original rasterized articulated character rigs, seven environment variants, and an industrial synthesizer with per-boss tonal roots and phase-dependent rhythm.

Status: development artwork and synthesized score. These are not finished high-density sprite sheets or mastered production music. The user's concept sheet was used only for design reference; no cropped portions were shipped. PixelLab and Higgsfield APIs were not used, and no external asset-generation charges were incurred by these tools.
